# DESIGN.md — FX Lot Calculator

計算画面（`index.html` の `#screen-calc`）の改修で採用したルール。以降の画面もこの規則に合わせる。
参考: iOS アプリコンセプト画像（オフホワイト・墨・深緑の3色、ロット数を主役にした構成）。

## 1. 役割と優先順位

1. **主役は「計算ロット」と「通貨数」**。地色の上に直接置き、カードで囲まない。
2. 次に「想定損失」チップ。結果の意味（いくら失うか）を1つだけ添える。
3. 入力（通貨ペア／売買／価格）は1枚のカードにまとめる。関連情報だけを同じカードに入れる。
4. 「今日の残り枠」は1行。内訳（日次上限・確定損失・保有想定・採用値・調整スイッチ）は `<details>` で畳む。
5. 主操作「〇〇 lot をコピー」は入力の直下・全幅・緑。副操作「保有分に追加」はテキストリンクに降格。

## 2. 配色トークン（`style.css :root`）

| 用途 | ライト | ダーク |
|---|---|---|
| 地色 `--bg` | `#F7F6F2` オフホワイト | `#141412` |
| カード `--card` | `#FFFFFF` | `#1E1E1B` |
| 本文 `--ink` | `#111111` 墨 | `#F2F0EA` |
| 副文 `--ink-2` | `#4A4A47` | `#C9C6BE` |
| 補足 `--muted` | `#6E6D68`（地色に 4.9:1） | `#9C9A93` |
| アクセント文字・線 `--green` | `#0F4D3A` 深緑 | `#5FB894` |
| アクセント塗り `--green-fill` | `#0F4D3A`（白文字 9.8:1） | `#1E6B4F`（白文字 6.5:1） |
| 淡い緑 `--green-soft` / 文字 `--green-ink` | `#E4EFEA` / `#0B3B2C` | `#1C3A2F` / `#A9DEC6` |
| 警告 `--red` / 淡 `--red-soft` | `#B42318` / `#FBEAE7` | `#F08A7E` / `#3A211E` |
| プレースホルダー `--placeholder` | `#8E8D88`（白に 3.3:1 以上） | `#7F7D77` |

- 緑は「主ボタンの塗り・選択中の状態・フォーカス線・アクセント文字」にだけ使う。装飾には使わない。
- 文字を載せる塗りは `--green-fill`、文字や線は `--green`。ダークテーマで両者を分けるため。
- 赤は「エラー」「残り枠ゼロ」だけ。
- 補足文字は `--muted` を使い、地色に対して 4.5:1 以上を保つ。

## 3. 文字組み

- 書体はシステムフォント: `-apple-system, "SF Pro Text", "Hiragino Sans", "Hiragino Kaku Gothic ProN", …`。1ファミリーで通す。
- サイズ尺度（px）: **12.5 / 13 / 14 / 15 / 16 / 17 / 24 / 28 / 68**。
  - 68 = ヒーロー数字（7〜8文字で 52、9文字以上で 40 に自動縮小。359px 以下では 56 / 44 / 34）
  - 28 = 画面タイトル、24 = 入力値、17 = 通貨数・主ボタン・行の値、15〜16 = 行ラベル、13 = フィールドラベル・補足、12.5 = 注記
- 太さ: **700 はヒーロー数字だけ**。600 は主ボタン・選択中セグメント／タブ・行の値・通貨ペア名・画面タイトル。本文・ラベル・補足は 400、入力値は 500。
- 和文の `letter-spacing` は 0。負のトラッキングはヒーロー数字（-0.035em）のみ。`uppercase` は使わない。
- 数字はすべて `font-variant-numeric: tabular-nums`。桁区切りあり（`toLocaleString('ja-JP')`）。クリップボードには桁区切りなしの素の値を入れる。

## 4. 余白・グルーピング

- 画面の左右余白 16px。カード内の左右 16px。
- 関連するもの同士は近く（フィールドラベルと値 2px、値と補助文 10px）、グループ間は広く（カード間 12px、主操作の上 18px）。
- カードは「入力」「残り枠」の2枚だけ。ヒーローと主操作はカードに入れない。カードの入れ子は禁止。
- グループ見出し（「価格」「許容損失」のような小見出し）は置かない。カードの中身が見出しの役目を果たす。

## 5. 部品

- **入力欄**: ラベル小（13px muted）を上、値大（24px/500）を下、2px の下線。通常 `--line`、フォーカス `--green`、エラー `--red`（ラベルも赤）。`caret-color` は緑。
- **セグメント（買い／売り）**: 選択中は `--green-fill` に白文字。非選択は `--control` 地に `--ink-2`。
- **下線タブ（価格／pips）**: 選択中は緑文字 600 + 2px 下線。非選択は muted 400。
- **行（許容損失・残り枠）**: 左ラベル 400、右に値 600 + 補足 muted、右端にシェブロン。タップできる行は `<button>` または `<summary>`。
- **主ボタン**: 全幅、高さ 52px 以上、17px/600、アイコン＋「{値} lot をコピー」。無効時は `--control` 地に muted 文字（不透明度で薄くしない）。成功時は `--green-ink` 地でチェックアイコン＋「{値} をコピーしました」を 1.6 秒。
- **チップ**: `ok` 淡緑、`warn` 淡赤、`muted` 灰。ヒーロー直下に1つだけ。
- **アイコン**: すべて 24 グリッドの線画 SVG、`stroke-width 1.8〜2`、`round` cap/join。絵文字・別シリーズは混ぜない。
- タップ対象は 44px 以上（タブ・アイコンボタン・下線タブ・セグメント・行）。

## 6. 状態

| 状態 | 表示 |
|---|---|
| 未入力 | 数字は薄い `0.00`、通貨行「価格を入力すると計算します」、灰チップ「エントリーと損切りの価格を入力」、主ボタン無効 |
| 数値でない入力 | 該当フィールドを赤下線＋赤ラベル、補助文とチップに「数字で入力してください」 |
| 買いで損切りが上／売りで下 | 損切りフィールドを赤、「買いの損切りはエントリーより下に」 |
| 残り枠ゼロ | 数字 `0`（薄い）、赤チップ「残り枠がありません。今日はここまで」、残り枠行の値とアイコンを赤、主ボタン無効 |
| 大きな桁 | ヒーロー数字を段階縮小、横スクロールさせない |
| コピー成功 | ボタン自体が変化（上記）。トーストは失敗時のみ |
